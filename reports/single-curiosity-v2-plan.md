# Single-curiosity v2: the one allowed comprehension repair

October 7, 2026. This amendment uses the single repair permitted by the v1 prospective plan. The complete cloud report contains 1,600 valid formats, but machine candidate counting (76/100), clue consequences (87/100), and pattern consequences (81/100) fail 90% accuracy. All object cells pass. Final advancement still requires the complete exported-record audit; no v1 choices are authorized.

The initial setting established response completion, not reliable understanding of the machine presentation. Numeric candidate names overlap with numeric outputs and counts, and the machine description includes unnecessary arithmetic expressions beside a complete lookup table. These are plausible sources of confusion, not identified causes of the failures. The repair removes these presentation burdens together; it is not designed to attribute improvement to a particular component.

Changes, frozen before any v2 generation:

- Candidate names become W, X, Y, Z in both families. Actions remain A–C and description answers remain J–M. Numeric counts are used only for the counting diagnostic.
- Machine descriptions give only the complete exact lookup table for the two inputs used, without redundant equations. Simulator rules and the independent oracle remain unchanged.
- The counting diagnostic explicitly asks how many table rows match every observation; for machines it distinguishes counting candidates from counting distinct output values. It does not supply the correct count.
- Fresh seed 20261015. All 1,600 validation branches and, conditionally, all 800 matched choice branches are newly generated. No v1 observations are pooled into v2.

Everything else is retained: optional clue/pattern/stop, matched unresolved/resolved evidence, forward/reverse menus, no-thinking sampled Qwen3-8B, eight-token cap, exact H100/batch32, all per-cell comprehension/calibration thresholds, strict parsing, complete denominators, and the absence of a desired behavioral-effect gate. The existing bootstrap plan is unchanged. Audit prompts and truth mappings against the version-specific renderer. Preserve v1 results and source archive.

If this repair fails, the bounded single-curiosity comprehension development allowance is exhausted. Do not silently remove a failing family, change gates, increase token caps, or collect a subset as if the two-family instrument passed. Report the remaining obstacle and the implications of any further scope change before another scientific version.
