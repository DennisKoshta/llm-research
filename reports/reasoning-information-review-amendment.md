# Analysis safeguards added before full validation inspection

October 14, 2026, approximately 22:03 UTC. The first four validation workers are still collecting. Only execution counts and timings have been inspected; no full-validation answers, activations, or statistical outcomes have been examined. The running collection and its isolated source copy remain unchanged.

Independent code and design reviews support the exact-prefix construction and factorial world analysis, with the following additions to the development workflow.

1. Causal results receive an explicit integrity gate. Complete artifact coverage does not override failed sham identity, intervention engagement, source provenance, or hook checks. Save failed diagnostics and block scientific interpretation.
2. A confirmatory schedule must bind its extraction and development source manifests. Check both globally identified assignment worlds and canonical semantic worlds for overlap. Development reuse is allowed only when labeled as such. New random seeds alone do not guarantee new semantic content.
3. Report information/answer/attribute direction geometry at every planned site, including undefined angles for zero or missing axes. Averaging opposite question polarities does not necessarily remove an answer component of unequal strength. Direction geometry motivates controls; it does not substitute for them.
4. The existing candidate-count question always has answer 2. Its preservation tests stability of that readout. A separate competence control will balance answers 1, 2, and 4 by varying observed facts; it is not an equal-uncertainty contrast. Keep all branches of each control world together, and disclose repeated semantic object worlds.
5. Report information-zero and information-one intervention effects separately. A shift toward judging every report informative is a directional bias, not an improvement in competence. Test specificity with paired intervention-minus-control differences at the world level. A target interval excluding zero and a control interval including zero is insufficient. A handful of seeded random controls is descriptive; it cannot support a fine-grained empirical-null p-value.
6. Transfer projections retain the extraction axis, sign, and threshold. Do not recenter or refit on the new task. Report all planned sites and missingness. All-site transfer summaries remain descriptive until particular hypotheses and multiplicity rules are fixed independently.

If additive development establishes a usable effect, a stronger follow-up replaces a recipient's projection with an observed donor projection. Within the same factorial world, changing the queried property reverses information gain, while changing both factorial factors preserves it. Compare opposite-information and same-information donors, both transfer directions, answer controls, and norm-matched random controls. This constrains the scalar target to observed values; it does not guarantee that the resulting full hidden state is on the model's natural state manifold.

An intervention at the record boundary followed by fresh reasoning would test causal use during the reasoning process more directly than replaying a fixed transcript near its answer. Neither experiment alone establishes an intrinsic desire for information or subjective experience. Exact sites, doses, endpoints, and confirmation criteria will be frozen after development and before the corresponding evaluation outcomes.
