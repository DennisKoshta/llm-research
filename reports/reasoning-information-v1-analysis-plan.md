# Representation analysis and fixed-transcript interventions — development plan

Frozen conceptually before inspection of the full validation trajectories, October 14, 2026. This is a development analysis, not a preregistered confirmatory result. The full validation execution is frozen independently.

## Representation questions

The primary representation contrast is query-relative information gain at constant total task uncertainty. For each world, retain all four known-attribute × queried-attribute cells. The contrast is `(h01 + h10 - h00 - h11) / 2`: positive means a report supplies the previously unknown property. Its factorial construction balances the two attribute main effects. Only complete four-cell groups contribute to a position; availability is reported explicitly. Do not condition on correct answers.

Fit using indices 0–49 only. For each family and a pooled source, fit separate new-question and already-known-question contrasts, plus their equal-weight average using worlds complete for both polarities. An additional half-difference estimates the component associated with the reversed Yes/No answers. Save known-attribute and query-attribute main-effect directions as controls. Report the angle between information and answer contrasts; do not assume they are independent. Pooled sources give equal weight to each family.

Evaluate indices 50–99, across each question kind and both families, at all four captured layers and seven positions. Report information-gain AUC, threshold accuracy using the extraction midpoint, mean within-world factorial projection, and within-world concordance. Bootstrap whole worlds for uncertainty on the mean factorial projection. AUC and accuracy are descriptive development metrics; selecting a favorable cell does not establish statistical confirmation. The direction learned on one polarity must be tested on the opposite polarity, where the correct answer reverses. Memory and count questions provide further task controls. Fixed token stages can have different available world sets; report missingness and do not infer a temporal rise from a changing sample.

Audit exact prompt overlap and semantic-world overlap between extraction and development. The object vocabulary has finitely many combinations, so index separation is not a guarantee of semantic novelty. Later evaluation uses disjoint vocabulary and a second prompt template, with all world branches held together.

## Causal follow-up design

The economical first causal experiment holds the entire visible prompt and generated reasoning transcript fixed. Replay the original exact token IDs through the final whitespace before the first non-whitespace final answer token. Exclude the answer token. Inject at the processed closing-think token or the last prefix token, with no hooks during subsequent generation. Report that this is conditional on the frozen transcript, not an intervention on naturally generated reasoning. Keeping text fixed prevents changed written explanations from being the sole cause of an effect; it does not itself prove a motivational state.

Before interpreting interventions, compare unsteered teacher-forced replay against recorded incremental-decoding distributions on the first two world indices in each family, all five kinds and four cells (80 assigned cases). Require complete eligible coverage, identical greedy allowed-label choices, absolute differences in full-vocabulary label probabilities at most 0.03 for every label and at most 0.01 for at least 99% of labels. Report actual differences and missing eligibility. A failure leads to a technical investigation, not relaxed thresholds or scientific pooling. Also check capture parity and zero-dose identity, hook cleanup, other-row isolation and norm-matched seeded controls.

Interventions will compare positive and negative information directions, the answer-related contrast, known/query controls, zero-dose, and seeded random directions. Their layer and dose schedule will be frozen after representation development but before intervention outcomes. Use paired final-continuation seeds across arms, retain invalid outputs, and measure both label probabilities and completed responses. Assess factual recall and candidate-count preservation. Changing both novelty judgments and action choices may reflect information appraisal; it is not automatically a curiosity drive. A stronger motivational claim additionally requires selective effects on optional information acquisition with appraisal and competence preserved.

The final held-out causal test will use fresh assignments and disjoint lexical/template conditions after development choices are frozen. No claim about subjective experience follows directly from successful decoding or steering.

## Transfer control motivated before validation inspection

The current factorial task equates information gain with whether the queried property differs from the explicitly observed property. Holding total uncertainty fixed and reversing question polarity does not eliminate this shortcut. A stronger generalization test therefore needs different named properties whose values can nevertheless already be inferred from the candidate table.

Prepare a separate relational transfer task with three binary properties and four distinct candidate rows. Two properties share the same latent bit (with independently counterbalanced polarity); the third uses a second independent latent bit. Observing the third displayed property always leaves two candidates. Depending on which of the other two properties is correlated with it, a report of the first or second property supplies zero or one bit. Thus both queried properties differ from the observed property, and candidate count remains two in every condition. Cross the identity of the correlated property with the queried property, preserving the same balanced factorial information contrast. Counterbalance property names, value order, row order and bit polarity. A prose rendering must state the same four finite possibilities without using the words informative or redundant.

Use explicit questions about candidate elimination or whether a report's value is already determined, rather than equating an unobserved literal fact with uncertainty reduction. Include recall and count controls. Freeze these assignments independently of representation fit, and validate the new task before interpreting transfer. Report this as a second task with revised questions, not an unseen template of the original exact instrument. Its principal purpose is to test the property-matching alternative. This design is conditional on an initial mechanism signal and remaining compute; no transfer outcomes have yet been collected.

The replay engineering capture tolerances are minimum cosine similarity 0.995 and maximum relative L2 difference 0.03 at every checked layer/position; zero-dose captures must be identical within the same execution cohort. These supplement, rather than replace, the prospectively specified label-distribution tolerances.
