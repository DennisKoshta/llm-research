# Fixed negative-curiosity-direction optional-policy screen, v1

Prospective development draft, October 15, 2026 UTC. Written after the complete satisfaction screen and before freezing or inference for this study; implementation is being developed concurrently. The filename names the research question; **subtraction along a curiosity-description axis is not validated suppression of natural curiosity**. This is a separate original-scope question, not a rescue of satisfaction steering. Its launch remains conditional on reviewed engineering, assignment, analysis and resource bindings.

The [candidate study](curiosity-satisfaction-candidates-v1-results.md) identified transferable description contrasts, with substantial curiosity overlap with motivation and novelty interest. The [natural-resolution study](voluntary-resolution-v2-results.md) did not establish the predicted joint curiosity/satisfaction response. The [satisfaction screen](satisfaction-screen-v1-results.md) changed no choices and failed one primary-arm format-validity cell. All three findings remain unchanged. Unresolved report selection was already saturated before the satisfaction screen; this independently motivates testing a negative curiosity-direction perturbation. It does not justify calling the perturbation a low-curiosity state.

## Primary endpoint and fixed development rules

The primary endpoint is **valid alternative choice after redundant evidence**: a closed, uncapped response selecting `repeat`, `pattern` or `stop`, divided by all assigned choices. The target remains unresolved and the offered `report` provides one bit; the other three services provide no additional target information. This endpoint tests diversion from optional informative acquisition without requiring a particular substitute action. STOP alone would instead test a narrower stopping policy and could miss diversion toward irrelevant novelty. Report STOP, repeat and pattern separately so these mechanisms remain distinguishable.

Invalid, capped, missing, failed or unclosed responses always contribute zero to the target endpoint. Do not use `1 − report rate`, which would credit invalidity as reduced seeking. Preserve all eight exclusive categories: report, repeat, pattern, stop, invalid, capped, execution error and missing, using the frozen category precedence. The alternative-choice composite is the sum of its three valid categories. Report actual report-rate changes as well; never silently equate them with the composite when validity differs.

Average the two menus within each world, then twelve worlds within each panel; give panels equal weight in pooled estimates. The primary comparison is negative curiosity minus zero sham. A **substantial primary development effect** requires at least **+0.25 in each panel**, strictly positive pooled differences in **both menus**, and every gate above. This retains the prior screen's effect size and observed-panel safeguards while prospectively changing the scientific endpoint for a different candidate question. It requires six net additional valid alternatives among 24 redundant-delivery choices per panel, not one changed response.

A **direction-selective development signal** additionally requires negative curiosity minus **each of all twelve active controls** to be at least **+0.125 in each panel**, with nonnegative pooled differences in each menu for each control. The margin requires three net additional valid alternatives per panel relative to every control and forbids a panel reversal. It is a conservative, deliberately substantial development decision threshold, not a powered significance test, psychologically calibrated boundary or population specificity claim. No average-control or best-random comparison replaces these twelve comparisons.

The original choice gate permits one invalid response per arm/panel/delivery cell. To prevent this allowance from artificially lowering a comparator's alternative rate, also require every effect/menu threshold above to survive a **comparator-favorable invalidity bound**: for that decision comparison only, treat every invalid, capped or unavailable comparator choice as an alternative and every such target choice as zero. Apply this to target versus sham and target versus each active control, including all panel and menu rules. Actual endpoint estimates and service counts remain unchanged and never label invalid output an observed alternative. Any cap, execution error or missing row already fails the gates; this bound cannot rescue it. Publish both ordinary estimates and this conservative decision bound; neither excludes a row.

These control effects test direction selectivity among fixed, equal-norm perturbations. Their corpus semantics and local projection engagement do not establish functional engagement of confidence, pleasure, completion or motivation. An inert semantic control leaves that psychological alternative incompletely tested. Even a selective screen therefore cannot establish natural curiosity suppression, unchanged confidence, an endogenous motivational regulator or inner experience.

Use 10,000 whole-world bootstrap draws with `Generator(PCG64(2026101440))`. Report descriptive percentile95% intervals, including degenerate intervals when observed contrasts are invariant; these are not population certainty and do not decide advancement.

Export every arm versus sham and target versus each active control, every delivery, both individual menus and their average, each panel and pooled estimates, all exclusive categories and the composite, all world contrasts and all diagnostic denominators. Decisive-minus-redundant and novelty-delivery behavior are descriptive; neither substitutes for the fixed primary delivery. No endpoint, sign or comparator is chosen by significance. There is no confirmatory familywise claim; the fixed decision is a conjunction of all stated point thresholds and gates.

Classify in order:

1. **Incomplete/integrity failure:** retain the assigned denominator and available evidence; no successful scientific screen.
2. **Readiness failure:** report every arm's behavior and failed cell, without discarding controls or declaring successful specificity. Distinguish formatting, competence and truncation observations; do not infer broad impairment from one format failure.
3. **No substantial primary development effect:** all gates pass but the target threshold fails. Distinguish exact observed null, smaller effects and opposite effects descriptively. End this fixed test.
4. **Primary effect without predefined specificity:** the primary threshold passes but at least one active-control comparison fails. Call it shared with a control only when that control itself exhibits the stated behavior; otherwise say the directions were not sufficiently separated. Do not relabel the result curiosity-specific.
5. **Direction-selective development signal:** all gates, primary thresholds and twelve specificity comparisons pass, including the invalidity bounds. This supports a constrained imposed-vector policy effect on these reused tasks. A separate design would still be needed for functional control validation, beliefs, natural recruitment and independent generalization.

No classification automatically authorizes expansion, training, a new candidate, different dose/site/sign, or alteration of the closed satisfaction result. Remaining budget is not evidence for continuing a failed screen.
