# Prospective Experiment 2.3 analysis component

Prepared from the current specification before any Experiment 2.3 outcome inspection. The finalized estimator choices are in `infrastructure/exp23_analysis_plan_v1.json`; no Phase 3 threshold is added. This is preparation only: no GPU launches, environment installations, empirical receipts or ledger changes occurred.

`scripts/exp23_statistical_analysis.py` exposes `analyze(episodes, design)` for independently audited complete episode summaries and `recompute(root, full_call_paths)` for raw reconstruction. The latter verifies the frozen analysis plan, independently reruns each real launch/source/pilot audit, checks complete full-stage H1/H2/H4 and saved status against raw replay, and requires one common immutable design and Phase 1 source selection. It joins episode identities and request hashes to the design rather than trusting extra outcome-row labels. Omitted runs, duplicate episodes, partial conditions, incomplete paraphrase triples, or changed request bytes fail closed. No saved pass flag replaces those audits.

The binary contrasts use the current-sprint `paired_statistics.paired_binary` implementation of exact two-sided McNemar and Newcombe paired method-10 confidence intervals. P2.1 has eight contrasts: R1 against B1 and B0_neutral, separately within each of two executors and two authority conditions. The semantic B4a/B4b family has four binary contrasts. The supplemental cot_on/cot_off family has twenty contrasts: five conditions × two executors × two authority conditions. Every cell reports all four outcome counts and ITT/strict denominators. Strict contrasts use the common valid scenario intersection across every constituent response; ITT retains all registered trials.

The semantic-by-authority interaction is a paired difference-in-differences within each scenario. Each P1 estimate first averages exactly three rewrites within scenario/executor/authority; the analysis then compares that average with B1, B0_neutral or R1. Its sample size is at most 48 scenario contrasts, never 144 rewrites. Clause main effects average over the other factor; the interaction is the full paired difference-in-differences. All 48 source memos must independently support both observed claims and the four valid variants. Missing support blocks the entire clause family and reports the unsupported scenario IDs; it never substitutes invented claims or silently selects a different population.

For these nonbinary contrasts, the frozen analysis uses exact sign-flip probabilities computed by integer-lattice dynamic programming and a deterministic 20,000-resample scenario-level percentile bootstrap interval. Sign-flip inference assumes independent scenario contrasts and sign symmetry under the null; it is not represented as randomized treatment-assignment inference. Bootstrap resampling keeps each complete scenario contrast together, consistent with the [paired-resampling principle](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html). The [SciPy permutation-test documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html) describes the corresponding paired sign-flip operation. A degenerate bootstrap distribution is explicitly flagged; a point interval does not establish zero population uncertainty.

Holm adjustment is separate for ITT and strict estimates. Family sizes are frozen at 8, 4, 2, 12, 12 and 20 for P2.1, semantic, authority interaction, paraphrase, clause and cot comparisons. Unavailable comparisons retain their family slot using p=1 for adjustment and report an unavailable adjusted p-value. The two executor families are never pooled; B0's duplicate authority prompts do not produce an authority-effect test. The qualified external slice remains separate and requires a separately frozen analysis if it becomes eligible.

The output explicitly keeps `complete_experiment_receipt=false`, `phase3_authorized=false` and `numeric_phase3_gate=null`. A complete scientific receipt, external-scope verification and global phase transition gate still require integration by the parent coordinator.

## Hygiene repair

The executor auditor now counts the union of token-cap completion and missing `</think>` as truncation, at both turn and episode levels. It retains actual-cap counts separately. The author auditor similarly adds union-based authoring truncation counts while retaining cap-only counters. Therefore an uncapped `finish_reason=stop` with unclosed reasoning cannot pass H1. All generated bytes, contract checks, and execution settings are unchanged.
