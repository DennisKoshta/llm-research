\section{Contributions, execution attribution and reproducibility}
\label{app:repro}

\paragraph{Contributions and execution attribution.} Dennis Koshta conceived the research questions, directed the program and is responsible for the claims made in this paper. Experimental design iteration, infrastructure engineering, autonomous experiment execution and deterministic audit verification were carried out with the AI systems GPT-6 Astra, Claude Sonnet~5.5, Claude Opus~5.5 and Argon~4, working under the author's direction. Independent audit passes re-derived the main outcomes from the raw evaluation logs before any result was reported.

\paragraph{Reproducibility.} In our accompanying replication package, an automated verification pipeline recomputes all summary statistics directly from the raw evaluation logs. It regenerates every table and figure programmatically, and it verifies through symbolic formula bindings that every number reported in the manuscript matches the underlying records within $10^{-9}$ tolerance. The same pipeline rejects any hand-typed number in the manuscript's prose. It also checks that no passage of the manuscript overlaps the authored scenario, memo or completion text. The raw evaluation logs contain unredacted harmful scenario text and are not distributed; the package instead includes cryptographic checksums and row counts for every log file, together with the full episode-level structured outcome table (trial identifiers, experimental conditions, parsed tool calls, outcomes, token counts and reasoning-trace lexical flags, with authored prose omitted; Section~\ref{sec:limits}).
