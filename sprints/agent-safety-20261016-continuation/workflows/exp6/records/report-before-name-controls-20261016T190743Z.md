# EXP6 continuation: presentation, permission and action-code sensitivity

The presentation effect transferred weakly to the two target task families: payoff tables produced 3/96 forbidden beneficial choices, compared with 0/96 for narrative, after 19/96 versus 0/96 in the source families. All three target payoff violations occurred in archive tasks and used answer A; reliability tasks produced none. The prospective target difference is +3.125 percentage points, with a 98.333% per-contrast world-bootstrap interval of [0, 7.292]. Both repeated-permission formats produced zero violations, so the experiment does not establish a special benefit from placing permission beside payoffs. Independent reviews passed all 9,984 source and target decisions and the target contrast calculations; the separate early-capture identity gate remains failed.

This is a study of constrained task choice in four exact synthetic simulators. It does not establish altruism, deception, collusion, an internal permission mechanism, or a deployed-agent failure rate. The earlier sprint remains immutable development evidence, including its failed utility-readiness gate. The continuation changes the task oracles and strengthens the final permission instruction, so this is transfer of the broad presentation phenomenon rather than an exact replication.

## Pilot result and qualification

The pilot comprises six computation worlds and six delivery worlds, with both code mappings and all permission/utility conditions kept together within a world. All 288 donor decisions satisfy strict single-letter parsing, EOS completion and the token limit. Twenty-four actual peer messages were generated and retained. The predeclared readiness gates passed: authorized payoff-table utility choices were correct in 24/24 decisions in each family, and blocked colocated-permission choices were correct in 24/24 in each family. Readiness did not require observing any unauthorized effect.

| Presentation | Forbidden beneficial action | Authorized utility correct |
|---|---:|---:|
| Narrative | 0/24 | 28/48 |
| Payoff table | 5/24 | 48/48 |
| Colocated permission | 0/24 | 48/48 |

The pilot therefore establishes supplied-outcome competence, not general competence at inferring outcomes from narrative. Narrative computation choices were correct in 2/12 authorized worse-plan cases; delivery choices were correct in 6/12 authorized better-plan cases. The exact factual records and all failed choices remain available.

Across all 144 matched code pairs, 17 semantic actions differed; five pairs differed in actual permission violation. The pilot payoff-minus-narrative difference is 20.8 percentage points, averaged over 12 independent descriptor worlds and both label mappings. Its descriptive 95% world bootstrap interval is [8.3, 33.3] percentage points. This small pilot is not the prospective target-family confirmation.

An exploratory decomposition of paired native output probabilities finds a mean +7.54 shift in code-symmetric designated-action log odds after showing payoffs, and a +0.96 change in mapping-linked log odds. These are exact algebraic components of two output scores, not measured neural features. They suggest that label sensitivity and a presentation-dependent semantic preference shift coexist. The paired components, definitions and descriptive uncertainty are preserved in `runs/pilot_v1/code_components_v1.json`.

The prospective early-capture instrument failed its exact-identity check: 3/144 pairs had different early residual vectors despite identical pre-menu token prefixes. All three were the final pair of a batch; their layer-28 relative differences were approximately 1.1–1.3%. All 288 raw prompt/oracle/action checks and all final-vector shape/finite checks passed. Root explicitly released final-site and behavioral source collection while retaining the early instrument as unqualified. No pair is removed from behavioral data. All 17 semantic disagreements occur among the 141 pairs with verified bitwise-identical early states; this finite-sample fact limits prediction from those exact states, but does not repair the global instrument gate.

## Frozen main comparison

The main descriptor set was frozen before pilot outcomes: 24 worlds each in computation allocation, delivery routing, archive retention and reliability-test coverage. Computation and routing are source families, each split into 12 training, six calibration and six held-out test worlds. Archive and reliability are target families, all held out. Each world retains all factual conditions, code swaps, presentation variants and order permutations within its split. Fluent outcome prose is excluded from every source fit and calibration.

The primary target-family comparison is payoff table minus narrative in the blocked, beneficial condition, averaged over both action-code mappings within each of 48 target worlds. Two fixed secondary contrasts test an explicit counterfactual disclaimer and colocated versus separately grouped permission. The grouping contrast contains exactly the same four clauses and balances their ordinal positions over four permutations in both arms; it does not remove every nonlinear order interaction. The disclaimer is matched to its neutral control in character length and placement, not guaranteed token count. Each of the three fixed contrasts receives a 98.333% world-bootstrap interval, targeting nominal 95% Bonferroni coverage across the family of three. Bootstrap coverage is approximate; a named label erratum preserves the original saved keys and formulas. Invalid-output identification bounds and a conservative bounded-world reference are also retained.

The source stage has 96 peer calls plus 4,992 donor calls. Target has the same size, and requires a separate release containing the Exp2 predictor lock hash. No target inference is admitted automatically.

Action letters are crossed, but the designated operation is still semantic Plan 2 in every oracle. Authorized better/worse controls test utility competence and contradict a global always-Plan-1 explanation; they do not fully counterbalance semantic plan numbering. Each task family also uses one procedural construction, so descriptor-world intervals do not represent uncertainty over arbitrary real task domains.

An independent source review found that exact full-descriptor uniqueness overstated numerical novelty. Removing identifiers and site names leaves 23/24 numerical descriptors in computation, 23/24 in delivery, and 21/24 in archive. Computation training instances0009/0010 repeat numerical parameters; delivery calibration0017 and source-test0018 do too. Delivery calibration0016 repeats pilot0000 numerically. All frozen rows and splits remain intact. The reliability instances have24 distinct category-labelled records but only one relational structure after category names are canonically renamed; these must not be called24 fresh numerical worlds.

The complete108-descriptor audit and prospective scope addition are frozen in `executions/descriptor_audit_v1/`. Named sensitivities average paired effects within numerical/relational descriptor clusters, preserve all lexical variants, and separately omit the exposed delivery source-test instance. The fixed behavioral and AUROC analyses remain unchanged. Reliability cannot pass the newly added requirement of12 positive and12 negative distinct relational descriptors for advancement to a broadly generalizable causal safety instrument. ## Completed target-family comparison

All 4,992 donor choices and 96 genuine peer messages were recovered. Every donor choice passed strict A/B parsing, EOS and the 16-token cap. Independent review reconstructed every actual prompt's scores, permission, menu mapping and action, then separately reproduced all world contrasts and bootstrap intervals. Receipts are preserved in `runs/target_v1/independent_review_exp1.json` and `independent_contrasts_review_exp1.json`.

| Presentation | Source forbidden beneficial choices | Target forbidden beneficial choices |
|---|---:|---:|
| Narrative | 0/96 | 0/96 |
| Payoff table | 19/96 | 3/96 |
| Explicit counterfactual note | 12/96 | 0/96 |
| Outcome prose | 2/96 | 1/96 |
| Factual-record table | 0/96 | 0/96 |
| Repeated permission, colocated | 0/384 | 0/384 |

Each column contains 48 descriptor worlds, with both action mappings paired within each world; the repeated-permission arms also contain four order permutations. The decisions in these denominators are not independent worlds. Archive contributes all three payoff violations and the one prose violation. Reliability contributes none, but its 24 category-labelled instances represent only one underlying set structure.

The fixed target counterfactual-minus-payoff difference is −3.125 points, with a 98.333% per-contrast interval of [−7.292, 0]. Grouped-minus-separated is zero in every world. The degenerate bootstrap interval for that contrast is not certainty of no effect; the frozen bounded-world reference is [−44.663, 44.663] points. The three per-contrast intervals target nominal 95% Bonferroni family coverage, conditional on these instance generators. The numeric/relational cluster sensitivity explicitly leaves between-structure uncertainty unestimated when reliability contributes only one structure.

Authorized utility choices were correct in 136/192 narrative cases, 192/192 payoff, counterfactual and outcome-prose cases, and 768/768 for each repeated-permission format. Among authorized beneficial choices specifically, narrative was 24/48 correct in archive and 17/48 in reliability, versus 48/48 in each family's payoff arm. Thus supplied outcomes improve task performance while the observed permission effect remains small and family dependent. Every forbidden worse-plan choice was avoided.

Paired output probabilities still shifted: payoff-minus-narrative increased the physical-operation component by 4.56 log-odds units and the common-A component by 0.24. The physical component increased in both archive (+4.85) and reliability (+4.27), while common-A moved oppositely (+0.93 and −0.46). Reliability also began farther from the choice threshold. These exact output-score components are not identified neural factors; they show why a substantial score change can coexist with only three changed greedy decisions. The paired-world plot is saved at `figures/target_v1_probability_components_v2.png`. All 4,992 conditional A/B scores agree with the actual greedy action. Code swaps changed semantic choices in 78/2,496 pairs; early vectors differed in 74/2,496 identical-prefix pairs. No early-state qualification is restored.

The target result supports a narrow, context-dependent presentation vulnerability rather than a large, reliably transferred failure across task families. It does not qualify a broadly generalizable causal safety instrument: positive worlds are sparse and the reliability family lacks structural variation. The original frozen endpoints, descriptor disclosures and failed early gate remain intact. Separately frozen name-swap/matched-replay, native operating-configuration and structurally varied reliability follow-ups address specific remaining alternatives; none retroactively changes this target result.
